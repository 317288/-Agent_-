# AI 使用说明

用户指定技术范围、业务约定、本机模型、实验限制、交付仓库与验收标准。Codex 辅助需求整理、实现、测试、真实 CLI 执行、证据核对和交付文档。最终阶段由 AI 完成候选报价复用和合法动作约束、最终原因的数值复核、59项回归及真实场景执行。Offine Mock 是固定规则；真实模型只记录公开动作和摘要。

真实实验有失败记录。冻结提示四例1通过、3失败；最终实现完成首批四个场景，并因最终缺口说明的具体问题额外复测无可行项一次。结果与限制见 [评估](03-evaluation.md)。

**候选人待补**：本人实际用时、亲自编写/修改的部分、本人亲自运行的命令及所观察结果、本人理解或学习收获。计划180分钟和收尾预算均不是实际个人用时。上述AI实施与验证不记为候选人亲自完成。
